# Epic - Authentication

## Objetivo

Permitir que usuários autenticados possam acessar os recursos protegidos da aplicação através de um token JWT.

---

## Escopo

- Login utilizando e-mail e senha.
- Emissão de JWT.
- Validação de autenticação.
- Proteção de endpoints privados.
