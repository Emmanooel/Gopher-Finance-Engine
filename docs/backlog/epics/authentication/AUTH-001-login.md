# AUTH-001 - Login com e-mail e senha

## Objetivo

Permitir que um usuário autenticado obtenha um token JWT para acessar os recursos protegidos da aplicação.

---

## Critérios de aceite

- [x] Receber e-mail e senha.
- [x] Validar se o usuário existe.
- [x] Validar a senha informada.
- [x] Gerar um JWT válido.
- [x] Retornar o token para o cliente.

---

## Fora do escopo

- Cadastro de usuário.
- Refresh Token.
- OAuth.
- Recuperação de senha.
- MFA.
