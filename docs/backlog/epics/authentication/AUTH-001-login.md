# AUTH-001 - Login com e-mail e senha

## Objetivo

Permitir que um usuário autenticado obtenha um token JWT para acessar os recursos protegidos da aplicação.

---

## Critérios de aceite

- [ ] Receber e-mail e senha.
- [ ] Validar se o usuário existe.
- [ ] Validar a senha informada.
- [ ] Gerar um JWT válido.
- [ ] Retornar o token para o cliente.

---

## Fora do escopo

- Cadastro de usuário.
- Refresh Token.
- OAuth.
- Recuperação de senha.
- MFA.
